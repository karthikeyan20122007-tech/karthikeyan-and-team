# FitBuddy – Phase-Wise Project Package

This package arranges the FitBuddy project according to the five milestones in the supplied project documentation.

01_Phase_1_Model_and_Architecture
02_Phase_2_Core_AI_Functionality
03_Phase_3_Backend_Routes
04_Phase_4_Frontend
05_Phase_5_Testing_and_Deployment
06_Complete_Runnable_Project

IMPORTANT: The phase folders are for project presentation/documentation. For actually running the application, open and run the project inside `06_Complete_Runnable_Project`.

Recommended college-project workflow:
1. Explain Phase 1.
2. Demonstrate Phase 2 AI functions.
3. Explain Phase 3 API routes.
4. Demonstrate Phase 4 UI.
5. Run tests and server in Phase 5.
6. Use Phase 6 as the final complete source code.
